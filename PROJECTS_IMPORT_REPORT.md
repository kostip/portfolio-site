# Отчёт об импорте проектных кейсов

Дата импорта: 17 июля 2026 года.

Источником истины для текста и последовательности служил обновлённый Markdown, для колонок, таблиц, переносов и служебных иконок — обновлённый HTML. Старые экспорты не использовались: неоднозначности удалось разрешить по двум актуальным форматам. Дочерних документов у четырёх кейсов не найдено.

## Общая архитектура

- Созданы страницы `/projects/tabs4me/`, `/projects/bravo-optika/`, `/projects/optima-servis/` и `/projects/amelisoul/`.
- Порядок: GOR `1` → Tabs4me `2` → Браво-Оптика `3` → OptimaServis `4` → AmeliSoul `5` → GOR. Существующий маршрут сам формирует цикл из записей с `order`; `demo-project` без `order` в цикл не попадает.
- В body новых Markdown-файлов нет `h1`: единственный `h1` выводит `ProjectLayout` из `title`.
- Для крупных разделов использован `h2`, для вложенных экранов и этапов — `h3`. Необоснованных скачков уровней нет.
- Использованы существующие `.two-column`, `.manual-columns`, `.table-scroll`, `.job-stories` и `.project-image`. Новые CSS-классы и inline-стили не добавлялись.
- Callout и `.lead` не использованы: обновлённый HTML не содержит соответствующих вынесенных блоков. Серые Notion-highlight в таблице AmeliSoul перенесены обычным текстом без декоративной заливки.
- Экспортные ссылки возврата на главную удалены. Единственная пользовательская внешняя ссылка — User Flow AmeliSoul в Figma — сохранена с `target="_blank"` и `rel="noopener noreferrer"`.
